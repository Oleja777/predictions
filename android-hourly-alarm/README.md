# Hourly Alarm (Android)

Простое Android-приложение на Kotlin, которое:
- по кнопке в `MainActivity` ставит точный будильник на начало следующего часа;
- показывает уведомление каждый час;
- после срабатывания автоматически планирует следующий час;
- восстанавливает планирование после перезагрузки устройства.

## Запуск

1. Откройте папку `android-hourly-alarm` в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите приложение на устройстве/эмуляторе (Android 7+).
4. Нажмите кнопку **«Запустить почасовой сигнал»**.

## Важно

- На Android 13+ нужно разрешение на уведомления.
- На некоторых прошивках нужно отдельно разрешить точные будильники (Exact alarms) в настройках приложения.
